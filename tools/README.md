# Tools

| Script | What it tests |
|--------|--------------|
| `mcp_responses.py` | MCP tool integration via the Responses API |
| `mcp_streaming.py` | MCP with streaming and direct connection |
| `function_tools.py` | Function tool schemas, execution loop, result chaining via function_call_output |

MCP scripts require an MCP server running. Function tools work with any model that supports tool calling.
